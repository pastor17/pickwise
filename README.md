# PickWise

> Product reviews & buyer's guides, built for overseas buyers.

This repository is reserved. The active content lives on the **`main`** branch.

## Branches

| Branch | Purpose |
|--------|---------|
| `master` | Default branch. Reserved for future use. |
| `main` | **Active development.** Hugo static site with all reviews, roundups, and guides. |

## Getting started

Clone the repo and check out the `main` branch:

```bash
git clone https://github.com/pastor17/pickwise.git
cd pickwise
git checkout main
```

Build the site with Hugo (v0.150+ extended):

```bash
hugo server
```

See `main` branch `README.md` for full documentation.
